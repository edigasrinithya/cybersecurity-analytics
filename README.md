# 🔐 cybersecurity-analytics
Cybersecurity data analysis using Excel, SQL and Power BI

## 📌 Project Overview

This project focuses on analyzing cybersecurity data to identify attack patterns, understand security incidents, and gain insights into cybersecurity threats.

The analysis was performed using Excel, SQL, and Power BI to transform raw data into meaningful insights through data cleaning, exploratory data analysis, and interactive visualization.

## 🎯 Project Objectives

- Analyze cybersecurity incidents and attack patterns.
- Identify high-severity security incidents.
- Examine attack success and failure rates.
- Analyze response times and data compromised.
- Build an interactive Power BI dashboard.

## 📊 Dataset

- **Total Records:** 100,000
- **Total Columns:** 19
- **Domain:** Cybersecurity

## 🛠️ Tools & Technologies

- Microsoft Excel – Data cleaning and validation
- Oracle SQL – Data querying and analysis
- Power BI – Data visualization and dashboard development

## 🔄 Project Workflow

### 1. Data Cleaning & Validation – Excel
- Checked for duplicate records and missing values.
- Performed numerical data validation.
- Applied the IQR method for outlier detection.
- Prepared the dataset for analysis.

### 2. SQL Analysis – Oracle SQL
- Imported and validated 100,000 records.
- Performed SQL queries for data exploration.
- Analyzed attack severity, response time, and attack outcomes.
- Used aggregate functions, filtering, grouping, and subqueries.

### 3. Dashboard Development – Power BI
- Created an interactive dashboard with 3 pages.
- Developed KPI cards and visualizations.
- Added slicers for interactive data exploration.
- Analyzed cybersecurity trends and incident patterns.
